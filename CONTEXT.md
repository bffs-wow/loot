# Synergy Loot Context

Domain glossary for the guild's objective, drama-free EPGP (Effort Points / Gear Points) loot distribution system.

## Language

### Roster & Standings

**Raider**:
An active guild member participating in or on standby for official raids.
_Avoid_: Core raider, member

**Recruit**:
A prospective raider in trial status requiring the Min EP Threshold before qualifying for Main Spec loot.
_Avoid_: Trial, initiate, pug

**Standby Raider**:
A raider signed up and confirmed online at raid start who is benched, receiving 100% Effort Point credit equal to active raiders.
_Avoid_: Bench, alternate, backup

**Priority Rating (PR)**:
The mathematical ratio of Effort Points to Gear Points (EP / GP) determining a raider's priority for loot.
_Avoid_: DKP, roll score, rank

### Effort Points (EP)

**Effort Points (EP)**:
Numerical credit quantifying a raider's attendance and time investment in official raids.
_Avoid_: DKP, attendance points, karma

**Raid Checkpoint**:
An attendance verification event during a Raid Night (On-Time: 25 EP, Mid-Raid: 50 EP, End-of-Raid: 25 EP; 100 EP total).
_Avoid_: Attendance tick, boss credit

**Min EP Threshold**:
The minimum banked Effort Points (100 EP) required before a raider qualifies to bid on Main Spec loot.
_Avoid_: Trial gate, probationary lock

### Gear Points (GP)

**Gear Points (GP)**:
Numerical quantification of the proportional value of loot received by a raider, scaled by item slot and level.
_Avoid_: Item cost, DKP spent, price

**Base GP Floor**:
The minimum Gear Points (100 GP) assigned to all raiders to prevent division by zero and penalize hoarders whose GP decays below the floor.
_Avoid_: Starting GP, zero floor

**Slot Multiplier**:
The coefficient applied to an item's base value based on armor/weapon budget (2H: 2.0, Trinket: 1.5, 1H/Ranged/Chest/Legs: 1.0, Shoulder/Glove/Belt/Boot: 0.777, Neck/Cloak/Ring/Bracer: 0.550).
_Avoid_: Slot weight, slot penalty

### Allocation & Tiers

**Main Spec (MS)**:
Primary spec upgrade tier charged at 100% GP cost, awarded to the eligible raider with the highest PR.
_Avoid_: Need, primary bid

**Minor Upgrade**:
A sidegrade or marginal upgrade tier charged at 50% GP cost, evaluated by PR only when no Main Spec claims exist.
_Avoid_: Sidegrade, +1, minor roll

**Off-Spec (OS)**:
Secondary spec upgrade tier charged at 25% GP cost, evaluated by PR only when no Main Spec or Minor Upgrade claims exist.
_Avoid_: Greed, secondary bid

**Rot**:
Unclaimed gear awarded for transmog, bank, or disenchanting at 0% GP cost (Free).
_Avoid_: Disenchant, shard, trash loot

### Ingest & Tooling Integration

**TMB Source**:
The raw That's My BiS export (`assets/tmb-data.json`) acting as the immutable source of truth for raid counts, bench counts, and received item history.
_Avoid_: Google sheet, CSV export

**CLM Standings Payload**:
The structured JSON export generated by the web app to initialize or update rosters and standings in Core Loot Manager via `/clm import` or `/clm importgeneric`.
_Avoid_: DKP string, lua export

**Gargul Priority Payload**:
The base64-deflated payload exported by the web app for import into Gargul via `/gl tmb` to display PR rankings directly in item tooltips.
_Avoid_: Gargul string, tooltip text

### Inflation & Maintenance

**Weekly Decay**:
The percentage reduction (10% to 15%) applied to every raider's EP and GP upon weekly Tuesday reset to eliminate hoarding and enable catch-up.
_Avoid_: Tax, point reset, deflation
